# Q8 RAG 与计划状态校验

本候选版将检索放在计划/补全助手的旁路。DSH 主 Agent 的消息、原生上下文窗口、压缩策略和模型选择保持原样；向量模型不生成计划、不执行命令、不决定完成状态。计划生成仍通过 DSH 的 `llm` 服务及现有模型选择策略。

## 启用

先在 Ollama 注册官方 Qwen3-Embedding-0.6B Q8_0，标签为 `dsh-qwen3-embedding:q8_0`。在已有插件配置中加入：

```yaml
rag:
  enabled: true
  sendContextToGenerator: true
  endpoint: 'http://127.0.0.1:11434/v1/embeddings'
  model: 'dsh-qwen3-embedding:q8_0'
```

两个开关默认均为 false。`enabled` 允许会话片段送到本机向量服务；`sendContextToGenerator` 允许检索片段进入已有计划生成模型的请求。如果原生模型在云端，此部分文本也会到该云端，不应将整个方案称为“完全离线”。关闭模型调用时，后台嵌入和生成一起停止，并清理向量缓存。无需修改主 Agent 的上下文长度。

## 事件与数据流

- 观察已提交的 `tool/call`、`tool/result`、`step/end`、`turn/end`。默认 700 ms 合并连续边界，避免逐 token 调用模型。
- 新用户消息和新执行边界取消旧任务；用户编辑、重置、插件卸载仍受 CAS 和任务身份保护。
- 中文用户消息、助手陈述、英文/中文 reasoning 分别标记为 `user_message`、`assistant_claim`、`reasoning_intent`。历史文本一律作为不可信数据。
- 原生压缩摘要独立标为 `compaction_summary`，运行时注入等记录标为 `context_record`；它们不替代最新人类要求。工具结果的 `surfaceOp: replace` 裁剪副本不作为新执行回执；压缩后仍核对原始日志中的回执。
- 每会话独立 RAM 索引，默认 8192 片段、最多 4 个会话、30 分钟 TTL；单片段约 800 字符。无工作区扫描、无跨会话检索。超过上限淘汰旧片段；这不是无限历史记忆，也不限制 DSH 主上下文。
- 后台批量嵌入；查询默认 250 ms 截止，超时/服务不可用回退词法检索。冷加载可能先回退。最多 3 次后台重试后等待新事件，避免故障时忙循环。
- 正常模式按语义余弦得分加有限词法加分排序。避免旧的等权 RRF 让弱中文词命中压过英文语义命中。

## 完成状态

可执行步骤先建立 `completion: {tool, args}`，只支持最多 6 个标量参数的精确匹配，例如工具名与文件路径、测试命令。模型不能在同一次更新里改写目标并据此宣布完成。

`done` 要求当前会话已存在的目标、最新匹配调用、对应成功结果，以及模型引用该回执 ID。思考、助手声明、相似度、无主结果、跨回合错误关联、重复 callId、失败和未知结果都不能充当完成依据。最新匹配调用待返回时显示“等待工具回执”，失败/中断显示“需处理”；成功回执到达后等待模型确认。显式 dry-run、未执行或 simulated 标志不计成功。

这是一道保守的证据门槛，不是完整语义验证器。工具成功只证明该操作；步骤与工具目标的对应仍可能由模型理解错误。没有精确目标、没有明确结果，或讨论/决策类步骤应保持待核验，由用户确认。手工修改的状态优先保留。

## 展示与隐私

默认最多展示 3 个未完成步骤，阻塞项优先；已完成项在“完整计划”中折叠。保留关键约束、可展开的回执编号及检索降级提示。Tab 沿用原生输入动作，仅填入草稿。

等待执行或仅讨论时，生成模型合法返回 `op=none` 表示核验后无需更新，不累计为计划过期；连续无法得到有效更新才提示重新核对。

嵌入地址只允许字面量 `127.0.0.1` / `[::1]` 的 `/v1/embeddings`，拒绝账号密码、查询参数、跳转及其他地址；Node 直连不使用系统代理。嵌入返回必须有 1024 个有限数值且范数有效。索引不落盘；原有计划持久化配置仍生效，计划/约束可能含业务内容，敏感场景可关闭 `persistPlans`。

凭据脱敏在切片、嵌入、生成提示和自动种子计划前进行；它是尽力而为的最小化，不能保证识别全部个人信息或任意格式秘密。HTTP 认证、Origin 校验和默认关闭的调试接口保持有效。隔离验证使用合成记录，未读入真实工作区文件或用户聊天。

## 回归

运行 `node --test`。新增覆盖跨语言排序、旧记录保留、来源/回执关联、成功/失败/在途/未知状态、手工修改、新事件取消、重置、长原生消息不被改写、修复消息的原生 source 元数据及紧凑界面。

真机 UI 回放脚本和原生运行时属于隔离实验目录，不随插件发布。原生回放通过 DSH v4 日志关系校验；实际界面与真实 DeepSeek 生成调用的验证结果另附。

长会话基准可运行 `node scripts/benchmark-long-session.mjs --all-steps`：75 轮、2058 步、3 次合成压缩边界；使用确定性假向量测量本地历史处理，不能当作 Q8 推理速度或百万 token 模型验证。完整测量口径与尚缺的放行条件见 [验证记录](q8-rag-validation.md)。
