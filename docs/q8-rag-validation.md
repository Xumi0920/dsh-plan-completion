## 本轮发现并修复

1. 原生压缩检查点也是 `user/message`，但 source 为 `compact-checkpoint`：单独标记为 `compaction_summary`，不覆盖最新用户要求，不充当完成证据。
2. 压缩后原生运行时可能再次写入 `runtime-context`：标记为背景 `context_record`，不替代人类要求。
3. 工具结果裁剪使用 `surfaceOp: replace`，正文可能丢失原始失败码：忽略该派生执行记录，仍核对原始回执。仅持有裁剪副本时保持无可用执行证据。
4. 弱词法命中压过跨语言语义命中；尚未调用的执行步骤被写成进行中；有效 `op=none` 被误当成过期，均有修复与回归。
