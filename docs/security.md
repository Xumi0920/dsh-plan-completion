# 安全与隐私边界

本页描述当前正式版本 **0.4.3**（六组件架构 + 默认关闭的零配置托管 Q8）的安全与隐私边界。历史 0.2.0 候选验证记录归档于 `managed-validation.md`，不代表当前发布状态。

## 计划与模型

- legacy 模式保留既有模型状态更新，显示“未经执行验收”；不能把它视为已验证完成。strict 模式按既有验收版本、原始调用与回执、依赖关系计算状态，英文思考和相似检索结果不授权 done。
- 人工确认是独立来源，仅适用于 manual scope；请求必须匹配计划版本与验收版本。模型不能伪造该记录；撤销确认会更改验收版本并使后续依赖失效。
- 默认 modelCalls=true。计划助手经当前选定 DSH provider/model 发送已有计划与近期证据，可能离开本机。固定路由配置缺失、解析为空或抛错时停止调用，不隐式切到其他供应商；设置变更取消旧生成/核对，过时结果不能提交。
- modelCalls=false 关闭插件生成调用，已有原始回执校验继续；不影响 DSH 主 Agent。warmBackfill 会读旧会话并可能触发助手调用，可单独关闭。保留原生上下文不等于保护正文免于外发。
- 脱敏规则仅覆盖部分已知秘密格式，不能保证删除所有个人、业务或自由文本敏感信息。

## 本地检索和托管进程

本地 Q8 默认关闭，向生成模型发送检索片段也默认关闭，二者独立。官方模型启动前核对 SHA-256；不下载权重或可执行程序。llama.cpp 是用户安装的第三方开源引擎，不是 DSH 自研内置引擎。

托管 server 只监听 127.0.0.1 随机端口，使用一次性密钥和随机模型别名；HTTP 直连、不读取代理、不跟随重定向。子进程以参数数组、shell=false、windowsHide=true 创建，不继承供应商凭据或任意 LLAMA_ARG_*。supervisor 只清理自己的子进程和临时密钥文件，Host IPC 断开也会触发清理。系统强制终止整个 supervisor、断电或恶意同用户进程不在这一保障范围内。

密钥不进入公开状态、日志或命令行；临时目录继承当前用户 OS 权限，POSIX 文件另设 0600。不能据此防御同一 OS 用户或管理员。可执行文件路径来自已鉴权配置，但插件不核验程序发布签名；请使用官方可信二进制和受控目录。

显式旧 endpoint 配置保留 external 模式，仍限定字面回环地址与 /v1/embeddings。该外部服务的生命周期、日志和自身隐私策略由用户管理。

## 存储隔离

计划、建议、验收记录和设置可写入 storageDir 的明文 JSON，不加密、不自动过期，存储按单 Host 假设设计。默认路径在显式 DSH_HOME 下；未配置 DSH_HOME 时仍为 ~/.dsh/plan-completion-data。明确的自定义路径保持原义。

不会自动把旧共享目录导入隔离环境。多个 profile 共用同一 DSH_HOME 时，仍应配置各自目录。persistPlans=false 关闭计划持久化，但设置页在非空 storageDir 下仍会保存设置；需要完全不落盘时使用空目录配置，并关闭 debugDir。索引向量只在内存中保存。

## 请求和诊断

所有 /plan-completion/* 路由在读请求体或操作前调用 DSH connection.requestRejection。无凭据/不可信来源拒绝，宿主鉴权服务缺失或契约异常返回 503。没有任意 Origin 反射或跨来源凭据 CORS。获得 DSH 合法 peer 权限的客户端可访问同一宿主内计划；这不是多人多租户 ACL。

生产路由为 state、replan、warm、verify、settings、confirm。debug、diag、theme、experiment、autojob、steps、reset 默认不注册；显式启用后仍须鉴权。请求体有容量上限，设置只接受已知字段和受限路径。

debugDir 默认为空；启用后的运行诊断按允许列表保留元数据，会话 ID 使用截断哈希，不保存模型正文、原始错误、请求 URL、cookie 或 DOM 正文。哈希是可关联标识，不等同匿名。显式调试实验仍可能含计划和模型评审内容，应按原始会话保护。

npm 包排除实验数据、截图、日志、测试适配器、模型和程序文件。Git 中的历史截图可能含昵称、用量及任务内容，不因本轮缩包而自动消失。当前文件扫描不能替代完整历史扫描或供应链审计。

## 验证边界

单测覆盖鉴权、来源分类、路由失效、取消/CAS、确认伪造、回执和依赖失效、端点约束、冷启动取消及进程环境过滤。真实本地 Q8 验证未鉴权 401、崩溃/空闲/Host 退出清理、代理零流量。隔离 Electron DSH Host 验证合成任务和组件启停；原生桌面点击验证因 Computer Use 被用户 Esc 停止而未完成。

不声明生产 profile 已部署、所有平台 GPU 已验证、真实 QQ/文章任务已执行，或本轮重新完成接近 1M/连续压缩压力测试。生产配置和凭据只读，合成测试结果与历史长测分开记录。

## 零配置下载（v0.3.0+）

- 托管安装只从固定的官方发布地址下载 llama.cpp 运行时和官方 Qwen3 Q8 模型；两者都有发布时写入的 SHA-256，校验通过后才原子替换为可用文件。
- 下载可走显式/环境代理或 Windows 系统代理（优先 curl），但代理变量不会传入 llama 子进程；子进程环境仍是白名单。
- 下载失败、哈希不符或平台不支持时保持 RAG 关闭，不影响计划与补全主流程；不会回退到未校验的镜像或任意 URL。

## 本地 llama-server 日志（v0.3.0+）

托管启动会把 llama-server 的 stdout/stderr 写入 `<storageDir>/logs/llama-server.log`（每次启动覆盖，单次最多约 2MB），失败时把最后 8KB 片段通过 IPC 返回给 Host 并显示在设置页的 “Q8 失败详情” 中。日志只在本机落盘，不随计划或模型请求外发；包含本地模型/可执行文件路径，不需要时可自行删除。
