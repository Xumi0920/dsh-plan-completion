# 安全与隐私边界

本页描述 **v0.1.1** 的安全与隐私边界。npm `0.1.0` 为旧版本（无鉴权、含原始诊断字段），请以 registry 最新版为准。

## 请求访问

所有 `/plan-completion/*` 路由在读取请求体或执行操作前调用 DSH 的
`connection.requestRejection(req)`。宿主负责 Host/Origin 检查及 cookie/API peer 鉴权；
无凭据、来源不受信任时返回 401/403，服务不可用或契约异常时返回 503，不退回“仅检查 loopback”。
插件不反射任意 Origin、不开放跨来源凭据 CORS。

默认只有 `state`、`replan`、`warm`。只有显式开启 `enableDebugRoutes: true` 才注册
`debug`、`diag`、`theme`、`experiment`、`autojob`、`steps`、`reset`，这些端点仍须鉴权。
DSH 是当前用户的可信宿主；本插件没有额外的多租户/逐会话 ACL。获得合法 DSH peer
权限的客户端仍能访问该宿主内的计划，不应把这一机制当作多人共享服务的隔离边界。

已核对本机安装版宿主源码：WebServer 不替插件鉴权；Electron 的 dsh-app HTTP 代理会
去掉 renderer 的 Origin 并注入宿主 cookie，因此客户端继续使用 same-origin fetch。
回归测试使用真实插件入口和模拟宿主服务；没有替换运行中的 DSH 或开展真实浏览器攻击测试。

## 哪些内容会发送给模型

默认 `modelCalls: true`。计划生成会把目标、近期用户/助手消息、工具错误及已有步骤证据
组成提示词，经 DSH llm 服务发送到**宿主当前默认 provider/model**。它不一定是历史会话
原先使用的模型，也不保证是本地模型。长度裁剪不是敏感信息脱敏；不要假定正文里的密码、
个人信息或业务数据会被自动识别和移除。

修复后不再遍历其他供应商挑选更快模型，也不缓存已过时的默认选择；无可用默认路由时使用启发式。
调试实验的评审也使用同一已选路线，结果不再声称来自独立跨模型评审。
`modelCalls: false` 可关闭**本插件**的全部模型调用并使用启发式，不会关闭 DSH 主 agent 的模型调用。

`warmBackfill: true` 会在打开旧会话时读取持久化历史以生成计划，可能触发模型请求。
设为 false 可关闭历史回填；若希望插件不向模型传输任何会话内容，同时设置 modelCalls: false。

## 本地日志、诊断及截图

- debugDir 默认为空，不写运行日志；设置目录或 DSH_PLAN_COMPLETION_DEBUG_DIR 后才启用。
- 运行日志仅保留允许列表中的操作元数据；会话标识使用截短 SHA-256。
  不保留模型正文、原始错误、配置内容、请求 URL/查询串、UA 或客户端请求体。
  会话哈希仍是可关联的假名标识，日志不是匿名统计。
- 客户端不再发送 DOM 正文、补全建议文本或完整页面 URL。
  诊断端点再次按白名单保留布局尺寸和布尔值，忽略额外正文。
- 显式运行调试实验时，内存结果和 debugDir 下的实验 JSON 仍可能含计划、建议、
  模型评审原文等内容。应按会话内容保护，不要把 research/debug 文件提交或公开。
  这些文件不加密，也没有自动保留期限。
- 仓库现有四张截图未见密钥/cookie 等凭据，但包含昵称头像、费用用量、模型与开发任务内容。
  这类演示信息已经公开；后续公开演示宜换为虚构样本或仅截取插件区域。

## 本次验证范围

原代码的未鉴权访问和隐式跨 provider 发送，均用合成数据、离线 mock 复现。
修复后的测试覆盖未授权/错误来源/鉴权服务缺失、诊断默认关闭、日志内容排除、
默认模型切换、关闭模型调用，以及计划状态和前端生命周期。

当前文本文件扫描未匹配常见私钥、GitHub/API/AWS 密钥模式；这不是完整 Git 历史扫描，
也不能证明不存在所有形式的秘密。没有在真实模型端点、生产 DSH/Electron 或 npm 发布环境
上执行端到端验收；本次运行结果不可替代部署后的兼容性验证。
